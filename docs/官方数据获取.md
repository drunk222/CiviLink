# 官方公开数据获取记录

日期：2026-11-08。

官方完整数据包公开可下载：https://chinavis.org/2024/document/channel2_data.rar 。此前连接失败是下载工具与官网TLS连接问题，不是访问权限或数据公开性问题。

HTTP响应确认归档大小为1,288,822,982字节，支持Range请求。已下载官方数据说明，保存在data/官方数据说明.docx，并提取为同目录TXT。

为避免1.29GB图片传输阻塞元数据获取，读取官方RAR5首部和末尾8MiB，定位XLSX文件条目，保留原始压缩数据及文件头，重建仅含数据表的RAR后提取。提取文件CRC32为8e9cfe46，与原RAR条目记录一致；XLSX所有ZIP成员CRC校验通过。

结果：

- data/official/人文可视化创意赛数据/博物馆数据精选.xlsx：官方原始数据表，未修改。
- data/official-records.json：逐行提取的完整元数据，未进行业务清洗。
- data/official-audit.json：初步审计和来源、校验记录。
- data/official-table-only.rar：由官方原始压缩条目重建的数据表归档，不是官方完整包。
- data/channel2_data.rar：已完成的官方完整归档。

核实4312条有效记录，4312个唯一Main_ID；用于图片匹配的ID只有4266个唯一值，所以不能用ID作为主键。11条记录缺失起始年，11条缺失终止年，应保留缺失值。

原表有8种机构标签，包含“北京故宫博物院（故宫专题）”235条，与官方简介所列机构范围存在差异，不能擅自合并到台北故宫。需在正式导入时核查。这是原始数据差异，审计保留原值。

0.3版已取得完整原包与全部图片。原包1,288,822,982字节，SHA256为5f4159c0fb624da681e75fec81b9dff2886ac0f89384a281196f34415eaf243e；没有发布方校验和，SHA用于本地完整性记录。实物文件清点为4312张JPG、1个XLSX及2个目录条目，与官网说明的4321张存在数量差异，未以补造图片弥补。4312张原图均通过原RAR文件CRC32校验，均与元数据记录成功关联，未匹配、歧义与解码错误为0。少数原文件名无法直接在Windows提取，使用安全哈希文件名封装解压，原图字节未改，原名保留在image-files.json。

完整原包在data/channel2_data.rar，下载记录在data/official-download.json，图像核验在data/image-audit.json。0.2阶段的部分整包下载片段已在完整校验后清理。10件精选研究案例仍独立计数。
