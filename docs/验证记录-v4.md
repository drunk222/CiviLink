# 清洗规则修订：公元前后年代、纹样边界与多标签

版本0.4，2026-11-23。对应 P0 与 P1 优化。

## 年代

- 新增公元前文本解析：`450 BC-250 BC`、`ca. 1100 BC-1000 BC`、`1200 BC - 1300 BC` 等按原文生成绘图年代，并保留 `rawStart/rawEnd`。
- 新增公元前单世纪展开：`4th century BC` → `-400— -301`，`3rd century BC` → `-300— -201`；不再压成单年。
- 新增 `dateRule`：`raw / ad-made / bc-range / bc-year / bc-century / century / pending`；新增 `datePrecision`：`range / year / century / unknown`。
- 修复 `lib.js` 的 BCE 区间显示：比较面板现在输出“公元前475—前220年”，不再丢失第二个“前”。

结果：4312条记录、4300条可绘制、12条缺失或待核不变；202条公元 `(made)` 规范化不变；新增50条公元前修正（18条符号/端点冲突，32条世纪展开），其中2条原本整段落入公元。

## 纹样

- 英文规则增加词边界：`dragonfly` 不再命中“龙凤”，`thunderbird` 不再命中“鸟禽”。
- 中文补充同形词排除：`龙眼`、`凤梨`、`雷鸟`。
- 纹样候选从794条修正为792条：龙凤104→103，鸟禽87→86。

## 材料与工艺

- 新增 `materialAll` / `techniqueAll` 多标签，按规则表顺序保存所有可识别类别；图表主类 `material` / `technique` 保持原口径不变。当前 `materialAll` 多条目标341条，`techniqueAll` 多条目标450条。
- 多标签规则使用词边界并排除复合词误配：`stoneware`、`bone china`、`woodblock`、`graphite`、`铅笔` 等不再产生额外类别。
- 新增 `materialAmbiguous` / `techniqueAmbiguous`。
- 补全依据新增 `type`：`title`（名称关键词）、`category`（分类推断）、`editorial`（人工校订）。
- 材料补全432条：405条分类、25条名称、2条人工；工艺补全92条：63条分类、29条名称。

## 重复馆藏号

- 新增 `accessionKey`、`duplicateGroupSize`、`duplicateIndex`、`duplicatePrimary`。
- 329个重复组、658条记录、329条超出首条；不删除任何记录，计数单位仍为元数据记录。

## 审计与验证

`data/normalized-audit.json` 新增：`bcNormalized`、`bcSignConflicts`、`bcEndpointConflicts`、`centuryExpanded`、`datePrecision`、`motifCounts`、`materialBasisTypes`、`techniqueBasisTypes`、`materialAllMulti`、`techniqueAllMulti`、`duplicateGroups`、`duplicateRecords`、`sourceCoverage`。

自动测试新增：公元前符号与端点、世纪展开、dragonfly/thunderbird、多标签、补全依据类型、重复馆藏号标记、审计计数一致性、BCE 显示格式。`node --test tests/official.test.js tests/lib.test.js` 共16项通过。

数据规模：4312条记录、4312个唯一 Main_ID、4312张图片；材料仍缺606条、技法仍缺1269条。
